## 阶段三：基础操控 — 键盘控制机器人移动

### 目标
通过键盘 WASD 控制 Go2 前后左右移动，相机画面实时可见。

### 设计思路

DimOS 已内置 `NavigationSkillContainer`，支持 `navigate_with_text("forward")` 等文本指令。我们实现一个键盘监听器，将按键映射为导航指令：

```
W/S     → 前进/后退
A/D     → 左转/右转
Q/E     → 侧移左/右
Space   → 紧急停止
F       → 开始跟随
R       → 开始扫描
H       → 保持位置
```

### 新增文件

| 文件 | 职责 |
|------|------|
| `robot-service/teleop/keyboard_controller.py` | 键盘监听 + 指令映射 |
| `robot-service/teleop/camera_viewer.py` | OpenCV 相机画面显示窗口 |
| `robot-service/teleop/__init__.py` | 导出 |
| `robot-service/scripts/run_teleop.py` | 一键启动脚本 |

### 任务

| # | 任务 | 预计 | 验证 |
|---|------|------|------|
| 3.1 | 实现 `KeyboardController` 类 | 45 min | 按 W 机器人前进 |
| 3.2 | 实现 `CameraViewer` 类 | 30 min | OpenCV 窗口显示相机画面 |
| 3.3 | 编写 `run_teleop.py` 启动脚本 | 15 min | 一键启动键盘+画面 |
| 3.4 | 真机测试：WASD 移动 | 15 min | 机器人响应键盘指令 |
| 3.5 | 真机测试：相机画面 + 移动 | 10 min | 看着画面操控机器人 |

**里程碑 M3：** 操作者看相机画面 + 按键盘 WASD 控制机器人移动，Space 立即停止。

## 阶段四：相机联动 — 机器人随相机视野行动

### 目标
相机画面与机器人运动形成闭环：操作者看到画面中的目标 → 机器人自动转向/跟随。

### 设计思路

DimOS 已内置 `PersonTracker`（YOLO11-pose）和 `PersonFollowSkillContainer`。我们通过 `robot-service` 的 API 下发指令，在相机画面中叠加跟踪框：

1. 相机画面实时显示，PersonTracker 检测到的人体画框
2. 按 F 键 → 机器人自动跟随画面中的人
3. 按 H 键 → 机器人保持位置
4. 画面中显示当前模式（IDLE/FOLLOWING/EXPLORING）

### 任务

| 任务 | 预计 | 验证 |
|------|------|------|
| 4.1 | 相机画面叠加跟踪框 | 30 min | 人出现在画面中时显示绿色框 |
| 4.2 | 跟随模式相机联动 | 30 min | 机器人跟随画面中的人移动 |
| 4.3 | 状态覆盖层显示 | 15 min | 画面显示 mode/速度/障碍物 |
| 4.4 | 真机测试：跟随 | 15 min | 人走动机器人跟随 |

**里程碑 M4：** 操作者看到画面中的人 → 按 F → 机器人自动跟随，画面中显示跟踪框 + FOLLOWING 状态。

## 风险与缓解

| 风险 | 缓解 |
|------|------|
| Go2 是 Air 版，无 SDK 权限 | 联系 Dimensional 获取权限或换 EDU 设备 |
| WebRTC 连接不稳定 | 降级 SDK2 + CycloneDDS 方案 |
| 相机画面帧率不足 | 降低分辨率到 320x240，或减少其他 stream |
| 双网卡配置失败 | 单网卡 + 端口转发到 192.168.123.x |
| 键盘控制在 Linux 终端无响应 | 使用 pynput 替代 curses，支持 GUI 和 SSH |
